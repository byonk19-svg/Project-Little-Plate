# Missing data and provenance report

Snapshot: 2026-08-02. This report records repository facts discovered during
inventory. It does not propose safety values.

## Confirmed gaps

- `supabase/seed.sql` is intentionally empty. There are no production foods,
  preparations, revisions, sources, tags, storage rules, or visuals to approve.
- Every catalog record found is generated by a test fixture under `tests/`.
  Fixture source names, URLs, reviewer roles, methods, textures, storage
  guidance, and visual metadata are synthetic and cannot establish production
  provenance.
- No qualified reviewer approval/reference ID or authority evidence is stored.
- No stable production record IDs exist. Runtime fixture IDs with UUID suffixes
  are test-run identifiers.
- The catalog schema represents source metadata, reviewer role/review dates,
  preparation method and shape/texture, skill/allergen/category tags, storage
  rules, and visual rights. It does not define a dedicated nutrition model or
  age/stage eligibility field.
- No committed nutrition claims, portion/frequency guidance, or developmental
  age-stage values were found in catalog records.
- The six review dimensions—including storage and conditional visual review—
  are not currently persisted as independent qualified review decisions in the
  production catalog model; this packet captures them externally until the
  separately authorized Ticket 23 implementation exists. Owner adjudication
  cannot replace qualified domain review.

## Not found during inventory

- Multiple competing production catalog sources
- Production duplicate/overlap decisions
- Production unsupported safety claims with attributable authorship
- A production visual-license manifest

## Owner decisions required before publication

The repository owner must decide how qualified evidence maps to each safety,
allergy, nutrition/stage, taxonomy, storage, and visual field; how conflicting
reviewer recommendations are adjudicated; which missing fields remain
explicitly unsupported; and how accepted recommendations are versioned without
rewriting history. Until then, unknown remains unknown and production remains
empty.
